# Primal-dual Langevin sampling

Code for the paper

> M. Burger, M. J. Ehrhardt, L. Kuger, L. Weigand. *Analysis of Primal-Dual Langevin
> Algorithms*. To appear in Foundations of Computational Mathematics.

The package `pdlangevin` implements the unadjusted Langevin primal-dual
algorithm (ULPDA) for sampling from densities of the form
exp(-f(Kx) - g(x)) with convex, possibly non-smooth f and g, together with two baselines: the
Prox-Sub algorithm of Habring, Holler and Pock (the limit λ → ∞) and a
forward-backward Langevin algorithm. The `experiments/` folder contains one
script per numerical experiment in the paper.

## Installation

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .
```

This installs all dependencies, including [ODL](https://github.com/odlgroup/odl)
pinned to [a commit](https://github.com/odlgroup/odl/tree/862c6a6d5592f8166e8f2f0b77764a0c2931129a)
from before its 1.0 release. ODL 1.0 changed its API and is not compatible with
this code.

## Usage

```python
import numpy as np, odl
from pdlangevin import primal_dual_langevin, RunningMoments, CallbackRunningMoments

space = odl.uniform_discr([0, 0], [1, 1], [128, 128])
noisy = space.element(np.random.default_rng(0).random(space.shape))
K = odl.Gradient(space)
f = 0.1 * odl.solvers.GroupL1Norm(K.range)                      # TV prior
g = 8 * odl.solvers.L2NormSquared(space).translated(noisy)      # Gaussian likelihood

rm = RunningMoments()
tau, lamda = 1e-4, 10                                            # sigma = lambda * tau
primal_dual_langevin(noisy.copy(), f, K, g, tau, lamda * tau, 1, 10**4,
                     callback=CallbackRunningMoments(rm), rng=np.random.default_rng(1))
mean, std = rm.mean, rm.std
```

## Reproducing the experiments

Each script runs the sampling, caches the results as `.npz` in
`results/<experiment>/` and creates the paper's figures from them. Running a
script again only redoes the figures; `--force` resamples. All parameters are
the ones stated in the paper and are defined as constants at the top of each
script.

| Paper | Script | Output | Runtime* |
|---|---|---|---|
| Fig. 1, 2 (Sec. 5.1) | `experiments/gaussians1d.py` | `results/gaussians1d/` | 5 min |
| Fig. 3, 4 (Sec. 5.2.1) | `experiments/l2tv_toy2d.py` | `results/l2tv-2d/` | 4 runs, 45 min each |
| Fig. 5, 6 (Sec. 5.2.2) | `experiments/l2tv_denoising.py` | `results/l2tv-images/` | 4 runs, 30 min each |
| Fig. 7 (Sec. 5.3) | `experiments/l2tgv_denoising.py` | `results/l2tgv-images/` | 2 images, 15 min each |
| Fig. 8 (Sec. 5.4) | `experiments/kltv_inpainting.py` | `results/kltv-inpainting/` | 1.5 min |

\* on a MacBook Air M4 (16 GB RAM). Each run uses a single core; runs of the same
experiment were executed in parallel with `--runs` (2D toy, L2-TV) or `--images` (TGV).
The 2D toy runs are dominated by the 20 Wasserstein distance evaluations per run using [POT](https://pythonot.github.io/).

```bash
python experiments/gaussians1d.py
python experiments/l2tv_denoising.py --runs 0 1     # runs can be split across processes
python experiments/l2tv_denoising.py --runs 2 inf
python experiments/l2tv_denoising.py                # afterwards: plot all cached runs
```

The test images in `data/` are photographs taken and a synthetic phantom generated by the authors. If you're extra curious: the cow is one of the ones on Coldham's Common, Cambridge (UK), while the tortoise is a Hermann's tortoise (*Testudo hermanni*) living in Schechen (Germany).
